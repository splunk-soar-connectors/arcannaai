**1.0.1**

* Targets Arcanna AI 1.93.0; every route and payload checked against its API.
* Removed: send bulk events (route no longer served by Arcanna), add notes, the asset's feedback mapping.
* send feedback: the label must be one of the job's labels (job labels mirror the SOAR closing statuses); closing notes and indicators removed (Arcanna ignored them).
* get event: an event not stored yet is read again until max_wait; the action fails when it is still unknown.
* get job: single-job route only, no fallback to the job list. get job by name: server-side exact title match.
* get outliers: v2 route, one row per outlier.
* Storages: asset default storage name and a storage_name parameter on send event, get event, export event, get reasoning and send feedback; send event returns the storage tag.
* query events: job_ids (optional list) replaces job_id and the asset's default job is no longer applied, so without job ids every job and storage the key may read is searched; filters must be a list (a single object is wrapped); page parameter, page and has_more in the summary.
* Output datapaths aligned with the API responses (category, outliers, job metrics, export, reasoning, reprocess).
* test connectivity: v2 health endpoint; fails unless it answers status OK for the API key.
* send event: severity parameter removed (deprecated by Arcanna).
* get event: max_wait limited to 300 s.
* query events: job_ids takes a list of integers (or comma separated text); decision_points_only parameter.
* Numeric parameters accept text such as "120.0"; a job id that is not an integer is reported as such.
* send feedback: username optional; when empty Arcanna attributes the feedback to the API key's user.
