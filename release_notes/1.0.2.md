**1.0.2**

* Playbook Arcanna_AI_Decision: ARCANNA_STORAGE setting, the decision is read on the storage tag the event was sent to; the first read waits up to FIRST_READ_WAIT_SECONDS (30) for the event to be stored; a read failing with HTTP 401 or an unresolvable storage ends the run as "read failed" instead of retrying; the unreachable "arcanna error" state is removed.
* Playbook Arcanna_AI_Decision: the HUD card colour follows the outcome (blue decided, red send/read failed or configuration error, grey timeout or no decision) instead of guessing from the label text.
* Playbook Arcanna_AI_Decision: the storage tag is kept in the outputs and the "Arcanna Decision" artifact; its event id, job id and storage tag are typed so the app's actions run from the artifact; one artifact per event and outcome; the HUD card shows the confidence as a percentage.
* New playbook Arcanna_AI_Feedback: sends the container's closing status as feedback for the event of the "Arcanna Decision" artifact, as the container owner, once per label.
* One archive: the playbooks ship inside the app archive under playbooks/ (Arcanna_AI_Decision.tgz, Arcanna_AI_Feedback.tgz), for SOAR releases that run playbooks on Python 3.13; the never-built Python 3.9 playbook package is no longer mentioned.
