* Initial release for Splunk SOAR 6.2 and later, built against Arcanna AI 1.60.
* Asset: base URL, API key, certificate verification, default job id, closing-reason-to-label mapping, timeout.
* Jobs: test connectivity, list jobs, get job, get job by name, list labels, get outliers, get job metrics, get platform metrics, start job, stop job, train job.
* Events: send event, get event (with optional wait for the decision), query events, export event, get reasoning, send feedback, send bulk events, add notes, reprocess event.
* Diagnostics: get api scopes.
